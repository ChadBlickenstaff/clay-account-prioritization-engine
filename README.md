# Clay Account Prioritization Engine

An account prioritization engine built during the AlphaForge GTM Engineering Bootcamp.

## Overview

This project explores how to prioritize target accounts by separating three distinct decisions:

- Qualification
- Prioritization
- Segmentation

Rather than combining everything into a single score, the workflow evaluates each layer independently so they can be measured, improved, and iterated over time.

## Problem

Many GTM workflows collapse multiple decisions into a single scoring model, making it difficult to understand why an account is prioritized or how the model should improve.

## Solution

This project separates each decision layer into its own workflow, allowing qualification, prioritization, and segmentation to be evaluated independently while supporting scalable account research.

## Key Learnings

- Different business decisions should be modeled separately.
- Good prioritization requires measurable feedback loops.
- Workflow design matters as much as model accuracy.
